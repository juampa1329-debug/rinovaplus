# P17 · TikTok, plan separado

Estado: diferido por decisión del propietario, 17 de noviembre de 2026. Sin cuenta ni aplicación de prueba disponibles. Esta fase adicional queda fuera del denominador original de 56 criterios/279 hitos.

## Decisión vigente

El propietario pidió que todo el trabajo de TikTok quede en un plan aparte. La matriz operativa actual P4-Meta comprende WhatsApp, Facebook/Messenger e Instagram. Se conservan el código existente de TikTok, sus pruebas y los textos/checkpoints históricos, sin acreditar pruebas de proveedor que no se han realizado.

El porcentaje canónico histórico y el cierre operativo Meta se reportan separados hasta conciliar formalmente ese cambio de alcance; mover trabajo de fase no constituye aceptación externa ni cambia pesos de forma silenciosa.

## Plan al retomar

1. Auditar la documentación oficial vigente: APIs, productos elegibles, regiones, revisión de app, permisos y acciones realmente disponibles. Elaborar una matriz de capacidades; no asumir paridad con Meta.
2. Crear cuenta/app de prueba y preparar OAuth, retorno, custodia de credenciales y cuentas autorizadas, dentro de las capacidades aprobadas.
3. Adaptar mensajes, comentarios, medios y recibos únicamente donde la API oficial seleccionada lo permita. Conservar una sola cola, firma, idempotencia y control IA/Humano.
4. Probar ingreso, salida, eventos, permisos insuficientes, revocación, expiración, duplicados, fallos y recuperación con cuenta real.
5. Aceptar el recorrido y su reversión con evidencia; dejar explícitas las capacidades no disponibles para esa cuenta/producto.

0/5 unidades aceptadas. No solicitar credenciales ni activar conexiones de TikTok mientras esta fase esté diferida.
