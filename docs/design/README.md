## Procedencia y comprobación

[Prompts exactos y procedencia image_gen](generation-prompts.json): una imagen por módulo, M-07 revisión 2. Archivos finales locales; no se requieren las copias originales fuera de esta carpeta para revisar el paquete. El agente coordinador inspeccionó visualmente las 12 imágenes generadas y verificó firmas/dimensiones PNG; esto prueba entrega y legibilidad principal, no aprobación humana.

Los marcos lógicos propuestos son escritorio 1440×1024 y formulario móvil 390×844. Los PNG tienen resoluciones raster distintas: desktop entre 1486–1488 × 1057–1059, formulario 853×1844; no son archivos físicos de 1440×1024/390×844 exactos.

## Límites

Solo texto CRM CBN, no identidad/logotipo oficial inventado. Español del preview y tokens son propuestas. Personas/programas/cifras ficticios; no se leen datos SIIE y producción permanece intacta. Cada PNG es raster, **no UI editable ni biblioteca de componentes**. La muestra editable requerida antes de implementar sigue pendiente; estos mockups no la sustituyen.

No se implementaron autenticación/permisos, estados secundarios, adaptación responsive completa o interacciones; no hay prueba funcional, navegador o dispositivo. Una imagen principal no demuestra todas las pestañas, cumplimiento/accesibilidad o variantes mobile/desktop. Aprobación solo por el propietario. Aprobar diseño **no autoriza implementación, Git, DB o despliegue**.
