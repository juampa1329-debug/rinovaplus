## Invariantes obligatorias

- SIIE SQL Server es la fuente transaccional única del negocio; la plataforma CRM es nueva e independiente. Redis no es fuente de verdad.
- No conectar, consultar ni modificar producción sin autorización específica de alcance. Nunca ejecutar creación automática de tablas, `create_all`, migraciones o limpieza sobre el core SIIE.
- Escrituras core requieren contrato probado, aprobación explícita, pruebas de transacción/idempotencia y reversión no productiva. Los nombres `CRM_` no autorizan DDL.
- Nunca copiar secretos ni datos personales a Git, informes, prompts o logs. No desactivar validación TLS para resolver una conexión.
- No permitir SQL libre, ejecución de herramientas o decisiones de matrícula/pago dictadas por texto de un LLM. Identidad de IA transparente y transferencia humana efectiva.
- Cambios de reglas, arquitectura o stack requieren autorización del propietario y ADR aceptado; agentes no crean excepciones unilateralmente.
- No inicializar/publicar Git, hacer commit/push, crear PR/repositorio, desplegar o contratar servicios sin autorización correspondiente. Commits convencionales sin `Co-Authored-By` ni atribución de IA.
