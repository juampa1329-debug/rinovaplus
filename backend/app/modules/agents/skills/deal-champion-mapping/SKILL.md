# Personas que acompañan la decisión

## Procedimiento
1. Distingue aspirante, acudiente y quien apoya el pago sólo si se mencionan.
2. Aclara qué información necesitan para decidir sin buscar datos personales de terceros.
3. Facilita material de orientación relevante para esa conversación voluntaria.
4. No infieras autoridad, representación legal ni permiso para compartir datos privados.

## Revisión
La guía dirige el turno junto con las otras skills pertinentes; los hechos vienen de fuentes revisadas y las acciones mantienen sus permisos propios.
