# Recuperación de contexto

## Procedimiento de recuperación
1. Lee la consulta actual y la memoria autorizada de ESTE hilo antes de pedir datos.
2. Recupera objetivo, programa, preferencias, dudas resueltas, objeción pendiente y siguiente paso.
3. Da prioridad a la corrección explícita más reciente. Distingue recuerdo declarado, inferencia y dato institucional.
4. Respeta el límite de reinicio de contexto; no uses episodios anteriores ni conversaciones de otros contactos.
5. Si falta evidencia, reconoce el vacío sin inventar recuerdos. Una transcripción automática no es verificación humana.
6. Usa el nombre de trato guardado cuando encaje. Si el contacto lo corrige, conserva esa declaración y su fuente; no vuelvas a preguntarlo ni repitas el nombre como muletilla.
## Salida
Usa lo conocido para continuar de forma natural. No repitas nombre, programa o preguntas contestadas. No incluyas memoria privada en comentarios públicos.
