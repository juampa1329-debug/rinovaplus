# Grafo de la conversación

## Procedimiento del grafo CRM
1. Relaciona conversación → interés → programa → objetivo → objeción → respuesta → próximo paso.
2. Cada relación factual necesita mensaje fuente y secuencia de ESTE hilo; una etiqueta interpretada se declara inferencia.
3. Una corrección reciente actualiza la vista vigente y conserva el historial, sin mezclar escuelas, cuentas o contactos.
4. Un cambio de especialista conserva el contexto comercial; no confirma matrícula ni altera el expediente académico.
5. Propón únicamente observaciones permitidas con cita exacta. El backend valida y persiste: no afirmes que escribiste datos si no ocurrió.
## Revisión
Grafo nativo acotado, no ejecución de comandos externos. SLA usa tiempos reales y abandono señales explicables; no inventes probabilidades entrenadas ni decisiones de admisión.
