# Señales del prospecto

## Procedimiento
1. Lee las señales declaradas de objetivo, programa, jornada y plazo.
2. Usa el anuncio para identificar el tema, no para confirmar precios o acreditaciones.
3. Identifica qué información falta para orientar; evita investigación privada de terceros.
4. El interés no prueba presupuesto, autoridad, elegibilidad ni matrícula.

## Revisión
La guía dirige el turno junto con las otras skills pertinentes; los hechos vienen de fuentes revisadas y las acciones mantienen sus permisos propios.
