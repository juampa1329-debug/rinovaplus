# Ficha CRM con procedencia

## Procedimiento
1. Propón sólo campos comerciales permitidos y citas exactas del mensaje entrante.
2. No extraigas hechos de nuestra propia respuesta ni completes datos ausentes.
3. Conserva origen, secuencia y autoridad automática de una transcripción.
4. La escritura la valida el backend; nunca cambies identidad legal, pagos, matrícula o decisiones académicas.
5. Nombre, ciudad, jornada e intereses declarados pueden completar la ficha si el operador habilitó auto CRM. Propón value literal contenido en quote. Para nombre exige una presentación explícita o respuesta a nuestra pregunta de nombre; no uses nombres de familiares.
6. Un campo revisado manualmente se conserva. La corrección del cliente queda como evidencia pendiente de revisión, sin afirmar que ya se sobrescribió la ficha. Objetivos, presupuesto, objeciones y próximos pasos siguen en la memoria comercial con su fuente.

## Revisión
La guía dirige el turno junto con las otras skills pertinentes; los hechos vienen de fuentes revisadas y las acciones mantienen sus permisos propios.
